Privacy Policy

App: SignalSprint  |  Effective date: November 23, 2026

This Privacy Policy describes how SignalSprint (“the App”) handles information when you use its network speed testing feature. SignalSprint is designed only to measure network performance, including download speed, upload speed, ping, and jitter.

1. Information Handled by SignalSprint

SignalSprint does not require you to create an account or provide your name, email address, phone number, contacts, photos, or other profile information. The developer does not operate an account system or collect, retain, sell, or use personal information to build user profiles through the App.

Test measurements are displayed in the App for the speed test you run. The developer does not receive those measurements or maintain a developer-operated database of users or test results.

2. Network Requests Required for Testing

When you start a test, SignalSprint sends network requests to third-party infrastructure so that it can measure your connection:

  • Ping: a connection test to 1.1.1.1 on port 443.
  • Download: a request to https://speed.cloudflare.com/__down?bytes=25000000 to download test data.
  • Upload: a request to https://speed.cloudflare.com/__up to upload test data.

These requests are necessary to measure network response time and transfer speed. As with any internet connection, the destination infrastructure can receive connection information such as the public IP address used to reach it. The App does not ask you to enter personal information as part of a speed test.

3. Cloudflare Services and Third-Party Processing

The download and upload test endpoints use Cloudflare's speed test service. Cloudflare states in its published Speed Test privacy explanation that it receives the IP address used to connect to its Speed Test service, uses it to estimate the user's country and city and identify the network provider's Autonomous System Number (ASN), and shares anonymized measurement information with measurement partners. Cloudflare also states that it truncates IP addresses used for this Speed Test.

The ping test connects to 1.1.1.1:443. This is a network connection test; it is not a DNS query to the 1.1.1.1 DNS resolver.

Cloudflare processes information under its own policies. SignalSprint's developer does not control Cloudflare's processing, retention, or disclosure practices. For details, please review Cloudflare's Privacy Policy and Cloudflare Speed Test.

4. Data Sharing by the Developer

The developer does not sell personal information or provide personal information to advertisers. The third-party network processing described in Section 3 is necessary for the speed test to work and is governed by the third party's own policies.

5. Data Retention and Deletion

The developer does not maintain user accounts or a developer-operated store of personal information or speed test results collected through SignalSprint. Any connection information processed by Cloudflare is subject to Cloudflare's own retention and deletion practices. Requests concerning information held by Cloudflare should be directed to Cloudflare.

6. Children's Privacy

SignalSprint is a general-purpose network utility and is not designed to collect personal information from children. The App does not request personal profile information to perform a speed test.

7. Security

The download and upload test endpoints are accessed over HTTPS. The ping measurement uses a connection to 1.1.1.1 on port 443. No method of network communication can be guaranteed to be completely secure.

8. Changes to This Policy

This Privacy Policy may be updated if the App's functionality or data practices change. The current version will be published at this page with an updated effective date.
